# Contributing

Thanks for considering a contribution to Job Finder Pro.

- Open an issue before large changes.
- Include clear reproduction steps for bugs.
- Never include API keys, CVs, job-applicant personal data, or other secrets in issues or pull requests.
- Keep changes focused and test them locally before submitting a pull request.
- By submitting a contribution, you agree that it may be distributed under the project's GPL-3.0-only license.
